# GPA Calculator

A beginner Python project that calculates GPA from letter grades and credit hours.

## What It Does

- Accepts multiple courses
- Converts letter grades into grade points
- Weights each grade by its credit hours
- Displays GPA rounded to two decimal places
- Accepts uppercase and lowercase letter grades

## Grade Scale

| Grade | Points |
|-------|--------|
| A | 4.0 |
| B | 3.0 |
| C | 2.0 |
| D | 1.0 |
| F | 0.0 |

## How to Run

With Python 3 installed, open a terminal in the project folder and run:

```bash
python3 gpa_calculator.py
```

Enter the number of courses, then each course's name, letter grade, and credit hours. Use positive numbers for credit hours.

You can also run this command in the repository's GitHub Codespace.

## Example

An A in a 4-credit course earns 16 quality points.
A B in a 3-credit course earns 9 quality points.

GPA = total quality points / total credit hours

25 / 7 = 3.57 GPA
